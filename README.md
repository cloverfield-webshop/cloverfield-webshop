# Cloverfield Webshop

**Fast, complete webshop software in PHP. One-time payment. Runs on your own hosting.**

No frameworks, no monthly fees, no external services required — just PHP, MySQL/MariaDB and Apache.

## Features

- **Installation in the browser** — the installer checks your server, creates the database and your admin account
- **Products** with options, packaging units, sale prices and up to five photos each
- **Selling by the metre** — for fabric, rugs or anything cut to size
- **Categories**, subcategories and a smart search
- **Orders, payments and PDF invoices**, confirmation e-mails and shipping labels
- **Payments** via your own Mollie or Stripe account (iDEAL, cards and more)
- **VAT rules per country**, discount codes and return requests
- **Four shop languages** — English, Dutch, German and French, each with its own clean URLs
- **Your own look** — colour schemes, logo and header photo
- **SEO built in** — clean URLs, sitemap, structured data and Open Graph
- **CSV import and export** for prices, stock, orders and customers
- **One-click signed updates** from the admin
- **Security first** — prepared statements, CSRF protection, login attempt limits and a separate admin session

## Requirements

| | |
|---|---|
| PHP | 8.1 or higher (tested on 8.2) |
| Database | MySQL 8.0 or MariaDB 10.5 or higher |
| Web server | Apache with `mod_rewrite` |
